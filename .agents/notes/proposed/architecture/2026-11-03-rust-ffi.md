KrKr2: **a C++ host calls Rust static libraries**, the boundary is a **stable C ABI**, and the
build is driven by **CMake orchestrating Cargo**.

---

## 1. The chosen stack

| Layer | Tool | Role |
|-------|------|------|
| Build integration | [Corrosion](https://github.com/corrosion-rs/corrosion) | CMake drives Cargo; unified `out/.../rust-target` |
| Rust → C headers | [cbindgen](https://github.com/mozilla/cbindgen) | Generates `bridge/include/krkr/*.h` |
| Cross-crate types | `krkr-ffi` | Error codes, `krkr_slice`, allocation conventions |
| C libraries → Rust | `krkr-sys-*` + `build.rs` | Link vcpkg; optional bindgen inside sys crates |
| C++ consumption | Hand-written thin wrappers | Only `#include <krkr/*.h>` |

```text
CMake ──► Corrosion ──► libkrkr_*.a
              └── build.rs (cbindgen) ──► bridge/include/krkr/*.h
cpp/plugins/*/*.cpp ──► krkr_*() ──► rust/crates/*/src/ffi.rs
```

---

## 2. Language-boundary comparison

| Option | Pros | Cons | Verdict |
|--------|------|------|---------|
| **C ABI** + cbindgen | Mature across compilers; minimal changes to C++ glue | Types must be hand-flattened | **✅ main boundary** |
| [cxx](https://cxx.rs/) | Type-safe Rust↔C++ | C++ must include cxx headers | ❌ |
| [autocxx](https://google.github.io/autocxx/) | Generates Rust API from C++ headers | Too much TJS header noise | ❌ |
| [UniFFI](https://mozilla.github.io/uniffi-rs/) | Multi-language bindings | C++ is not a first-class citizen | ❌ |
| Fully hand-written C headers | Full control | Drifts from Rust easily | △ only `common.h` |
| `dlopen` dynamic plugins | Hot-swappable | Conflicts with the existing static-link model | ❌ |

**Why C ABI:** the host is C++; incremental migration relies on `#ifdef KRKR_USE_RUST_*`;
multiple crates share `krkr-ffi`; and it fits the staticlib cross-compilation flow.

---

## 3. Build-integration comparison

| Option | Verdict |
|--------|---------|
| **Corrosion** | **✅** — single CMake entry point; can inject `KRKR_VCPKG_INSTALLED` |
| ExternalProject + hand-written cargo | ❌ |
| cargo-cmake | ❌ |
| Pure Cargo, manually linking `.a` | ❌ |

---

## 4. Header-generation comparison

| Option | Verdict |
|--------|---------|
| **cbindgen** | **✅** — `ffi.rs` is the single source of truth |
| cxx build.rs | ❌ |
| safer-ffi / Diplomat | ❌ |

**Convention:** all `#[no_mangle] extern "C"` functions live in `rust/crates/<crate>/src/ffi.rs`;
C++ includes only the generated headers.

|--------|---------|

## 6. Memory and ownership

| Scenario | Convention |
|----------|------------|
| Input buffers | Caller owns; Rust reads only |
| Output buffers | C++ allocates `(ptr, len)` |
| Heap objects | Opaque `KrkrXxx*` + `close` |
| Strings | Fixed-size, or query the length first |
| Errors | `KrkrStatus` + `krkr_last_error()` |

Types: `bridge/include/krkr/common.h` + `krkr-ffi`.
